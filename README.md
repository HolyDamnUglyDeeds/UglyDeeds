# UglyDeeds
I have no choice but to come up and speak again. Still Risking My Life, Still Fighting For the Greater Good And the Justice In One HEAVILY ILL man's dream.  


This is for vscode.dev, with github as the working storage space.

## Files:
- **.vscode** (folder of configure files for vscode.dev)
    - settings.json  
    - style.css (the css file of markdown)
    - my-snippets.code-snippets  
- **main.md** the main markdown file
- **README.md**  (this file)  
  
## How to Use:  
### A. Pure Markdown:  
Download the **main.md** from github. Open it with any markdown viewer / editor which suppoerted html tags and css files.  
  
### B. vscode.dev
- fork this repo
- open settings sync for your forked repo.
- create a **github Codespaces** for your forked repo, 

or 

- seach and open **vscode.dev**
- set settings sync, check all options, login github,
- set remote storage, login github
- enable the extensions
- open **main.md**, preview it.
